# Backend selection — 2026-11-09

**Selected: SiYuan 3.8.9.** It is the only candidate in this comparison that combines a released, official MCP server, a headless native kernel/CLI, a web document editor, and a native visual database without PostgreSQL or Redis. Its size is substantial, so it is downloaded separately, never embedded in Cherry.

## How sizes were measured

On macOS arm64, download release assets with `gh release download`; for Linux images use `crane v0.22.1 pull --platform linux/arm64 --format oci IMAGE PATH` and sum every downloaded OCI file with `os.path.getsize`. These are actual downloaded artifacts, **not RAM, installed container size, or equal-format apples-to-apples comparisons**. Docker was not installed, so the OCI layouts were downloaded without starting those images. Compressed layer sizes come from the selected platform manifest; images may need additional services.
