# cherry-memories-server

An npm-distributable Node service for Cherry Studio Space: SQLite pages, Eidos tables, Better Auth accounts, REST and MCP. Use Node 24.16 or newer. See [deployment](../../docs/deploy-server.md) and [architecture](../../docs/architecture-npm-backend.md) in the repository. Local and remote clients use the same API. There is one writer per data directory; the stdio command connects to the running server.

The package is AGPL-3.0-only. Its runtime dependencies and their registry-declared licenses are listed below from `package-lock.json`. The `@eidos.space/eidos-file` npm package is MIT; Eidos CLI and other repository components have their own licenses and are not included here. Node includes its own license and third-party notices. This inventory does not replace a complete distribution-license review.
